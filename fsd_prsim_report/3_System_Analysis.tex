 \section{Module Description}
 The Smart Price-to-Quality Product Advisor System is divided into multiple functional modules, each responsible for handling a specific operation within the system. These modules work together to ensure secure access control, efficient product management, accurate comparison, and intelligent recommendations. The main modules include:
 \begin{itemize}
    \item \textbf{User Authentication Module:}This module is responsible for handling user registration and login functionality. It allows new users to create an account and existing users to securely log in using their credentials. The system validates user data and ensures secure session management. Password encryption and authentication checks are implemented to protect user information. Once logged in, users can access product viewing, comparison, and recommendation features. However, users are restricted from modifying product data, ensuring data integrity.
    \item \textbf{Admin Authentication \& Management Module:}This module provides a separate and secure login system specifically for the Admin. The Admin has exclusive privileges to manage product data within the system. After successful authentication, the Admin can add new products, edit existing product details, update specifications and prices, and delete products from the database. This module ensures role-based access control, meaning only authorized administrators can perform these operations, while regular users have read-only access.
    \item \textbf{Product Management Module (Admin Only):}This module allows the Admin to maintain the product database efficiently. It includes functionalities such as adding new products with detailed specifications, editing product information, updating price details, and removing outdated products. The module interacts directly with the database to store and retrieve product information. It ensures that all product data remains structured, consistent, and up to date.
    \item \textbf{Product Viewing \& Category Selection Module:}This module enables users to browse products based on selected categories such as smartphones, laptops, appliances, or accessories. Users can filter products by brand, price range, or specifications. The system dynamically fetches relevant product details from the database and displays them in an organized format. This ensures users can easily explore available products before making comparisons.
    \item \textbf{Product Comparison Module:}The comparison module allows users to select multiple products and view their specifications side by side. It presents detailed attributes such as performance, features, ratings, warranty, and price in a structured dashboard format. This module simplifies decision-making by enabling direct comparison of different products within the same category.
    \item \textbf{Price-to-Quality Value Score Module:}This module is responsible for computing the Price-to-Quality Value Score. It uses weighted parameters such as specifications, performance metrics, user ratings, warranty, and cost. The algorithm processes these inputs and generates a score that reflects the overall value of each product. The product with the highest value score is identified as the best recommendation. This module ensures that recommendations are data-driven rather than based solely on price.
    \item \textbf{Recommendation Module:}Based on the calculated value scores and user-defined priorities (such as budget constraints or feature importance), this module recommends the most suitable product. It highlights the best-performing product and provides reasoning based on the evaluation metrics. This helps users make informed and unbiased purchasing decisions.
    \item \textbf{Database Management Module:}This module handles all interactions with the database. It stores user credentials, product details, specifications, ratings, and other relevant information. It ensures secure data storage, efficient retrieval, and consistency across system operations. All modules depend on this component for accurate and real-time data access.
    \item \textbf{User Interface Module:}The User Interface (UI) module manages the design and interaction elements of the system. It includes login pages, dashboards, product display pages, comparison screens, and admin management panels. The UI is responsive and user-friendly, ensuring smooth navigation across devices such as desktops, tablets, and mobile phones. Proper layout design improves usability and enhances overall user experience.
    
\end{itemize}
\section{Business Rules}
Business rules are specific guidelines, conditions, or constraints that govern the operations of a
business or system. They define how processes and activities should be conducted to ensure
consistency, fairness, and alignment with business objectives. Business rules help ensure that the
system behaves as expected and meets the needs of users or stakeholders.\\\\
\textbf{User \& Admin Access Rules}
\begin{itemize}
    \item The system follows role-based access control with two roles: User and Admin.
    \item Only registered users can log in and access comparison and recommendation features.
    \item A separate Admin login is required for product management.
    \item Users cannot add, edit, or delete products.
    \item Only Admins are authorized to add, update, or remove product data.
\end{itemize}
\textbf{Product Management Rules}
\begin{itemize}
    \item All products must contain complete details (name, category, brand, price, specifications, rating).
    \item Price must be a valid value greater than zero.
    \item Duplicate products within the same category are not allowed.
    \item Editing updates the existing record; deletion permanently removes the product.
\end{itemize}
\textbf{Product Comparison Rules}
\begin{itemize}
    \item Users can compare only products within the same category.
    \item The system displays side-by-side comparison of selected products.
    \item Filters (brand, category, budget) must return only matching products.
\end{itemize}
\textbf{Price-to-Quality Value Score Rules}
\begin{itemize}
    \item Each product must have sufficient attributes for score calculation.
    \item The system calculates a value score using weighted parameters (performance, features, ratings, warranty, price).
    \item The product with the highest score is recommended.
\end{itemize}

\section{Analysis of Architecture (and/ or) Algorithms}
{\large \textbf{MERN Stack Architecture}}\\\\
The Smart Price-to-Quality Product Advisor System is built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). This architecture ensures scalability, efficient data handling, secure authentication, and dynamic user interaction.\\\\
\begin{enumerate}
    \item \textbf{ Frontend Architecture}
    \begin{itemize}
        \item React is used to build a responsive and component-based user interface.
        \item It manages pages such as User Login, Admin Panel, Product Listing, and Comparison Dashboard.
    \end{itemize}
    \item \textbf{Backend}
    \begin{itemize}
        \item Node.js handles server-side operations.
        \item Express manages routing
        \item Role-based middleware restricts Admin functionalities (Add, Edit, Delete products).

        \item Business logic and value score calculations are processed on the server
    \end{itemize}
    \item \textbf{Database}
    \begin{itemize}
        \item MongoDB stores users and product data.
        \item Mongoose schemas enforce validation and data consistency
        \item Ensures secure and efficient data storage.
    \end{itemize}
    \item \textbf{Price-to-Quality Value Score Algorithm}
  
         The system calculates a weighted score based on:
 \begin{itemize}
\item Performance
\item Features
\item Ratings
\item Warranty
\item Price
\end{itemize}
Value Score = (Weighted Quality Parameters) ÷ Price
\begin{itemize}
\item Higher score indicates better value.
\item User-defined priorities adjust weight distribution.
\item The highest-scoring product is recommended.
        \item Built-in testing tools help verify score accuracy and system behavior efficiently.
    \end{itemize}
\end{enumerate}
\textbf{Why MERN?}\\\\
\begin{itemize}
\item Full-stack JavaScript environment
\item Scalable and flexible architecture
\item Secure role-based access control
\item Real-time and dynamic user experience
\end{itemize}
This architecture ensures accurate product evaluation, secure management, and efficient recommendation generation.

\subsubsection{Project Abstract}

This project focuses on developing a generalized, intelligent Product Selection and Comparison System that assists users in choosing the most suitable product across multiple categories and brands. The system allows users to first select the type of product (such as smartphones, laptops, appliances, wearables, or accessories) and then choose preferred brands before proceeding to comparison. Instead of relying solely on price, the application evaluates products using a flexible Price-to-Quality Value Score that considers specifications, features, performance metrics, user ratings, reviews, warranty, and cost. The system supports multi-product comparison, budget-based filtering, personalized priorities, and category-specific evaluation criteria.

    \item Price-to-Quality Value Score computation

    \item Multi-brand and multi-product comparison support

 \section{System Environment}
 
 \subsection{Software Environment}
 \textbf{React.js:}
 React.js is used for developing the user interface of the Smart Price-to-Quality Product Advisor System. It provides a component-based architecture that allows efficient development of reusable UI components such as Login pages, Admin Dashboard, Product Listing, Comparison Dashboard, and Recommendation pages. React ensures dynamic rendering, smooth navigation using routing, and real-time updates when filtering or comparing products.\\\\
 \textbf{Node.js:}
 Node.js serves as the backend runtime environment for handling server-side logic. It processes API requests, manages authentication, performs value score calculations, and communicates with the database. Node.js enables scalable and efficient handling of multiple user requests.
 \\\\
 \textbf{Express.js:}
Express.js is used to build RESTful APIs and manage routing within the backend. It handles user authentication routes, product management routes, and recommendation logic. Middleware functions are implemented to enforce role-based access control, ensuring that only Admin users can perform product modifications.
\\\\
 \textbf{MongoDB:}
 MongoDB is used to store user credentials and product information in a structured format. It manages collections such as Users and Products. Mongoose is used to define schemas, enforce validation rules, and maintain data consistency. MongoDB ensures efficient data storage and retrieval for comparison and recommendation processes.
\\\\

\textbf{Mongoose:}
Mongoose acts as an Object Data Modeling (ODM) library that connects Node.js with MongoDB. It defines structured schemas for product and user data and ensures proper validation before storing records in the database.
