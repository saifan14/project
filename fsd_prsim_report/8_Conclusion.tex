\chapter{CONCLUSIONS}

The Smart Price-to-Quality Product Advisor System was successfully designed and developed to assist users in making informed purchasing decisions through structured product comparison and intelligent evaluation. The system provides a user-friendly platform where individuals can explore products across different categories, apply filters, compare multiple items, and receive recommendations based on a calculated Price-to-Quality Value Score.

By implementing a role-based access control mechanism, the system ensures secure separation between User and Admin functionalities. While users can view, compare, and analyze products, only the Admin has the authority to add, update, or delete product information. This maintains data integrity and enhances system reliability.

The use of the MERN stack architecture enables efficient frontend-backend communication, secure authentication, structured database management, and scalable deployment. The weighted scoring algorithm ensures that recommendations are data-driven and unbiased, rather than based solely on price.

Through proper testing—including unit, integration, system, regression, and performance testing—the application was verified to function correctly and efficiently under different conditions. The system demonstrates strong technical, operational, and economic feasibility.

Overall, the Smart Price-to-Quality Product Advisor System achieves its objective of simplifying product comparison and delivering intelligent recommendations. The project serves as a practical example of full-stack web development integrated with algorithm-based decision-making and secure role-based system design.
