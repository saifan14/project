\chapter{TESTING}
\sloppy
Testing is a critical phase in software development, ensuring that the system operates correctly, securely, and efficiently. Without proper testing, the application may face issues such as incorrect calculations, broken functionalities, security vulnerabilities, or system crashes. In the Smart Price-to-Quality Product Advisor System, different levels of testing were performed, including unit testing, integration testing, system testing, and performance testing.

Unit testing verifies individual components such as authentication logic, product management functions, and value score calculations. Integration testing ensures that the frontend, backend, and database interact correctly. System testing evaluates the entire application workflow from login to recommendation generation. Performance testing ensures that the system can handle multiple users and product comparisons without delays. 
\noindent

\section{Unit Testing}
Unit testing focuses on testing individual modules of the system independently to ensure they function correctly.

For example:

Authentication testing verifies whether users and admins can log in with valid credentials and are denied access with invalid credentials.Product management testing ensures that Admin functionalities such as Add, Edit, and Delete products work correctly.Value score calculation testing checks whether the Price-to-Quality algorithm produces accurate results based on given inputs.Input validation testing ensures that incorrect or incomplete data cannot be submitted to the database.By performing unit testing, errors are identified early in development, improving system stability and reliability.
