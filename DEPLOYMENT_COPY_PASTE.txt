IMPORTANT NOTES

1. Never commit .env files to Git
2. MONGO_URI format: mongodb+srv://username:password@cluster.mongodb.net/database?retryWrites=true&w=majority
3. JWT_SECRET must be generated and unique
4. NODE_ENV must be "production" for production deployments

6. FRONTEND_URL: Set after Vercel deployment
7. VITE_API_URL: Use Render backend URL once deployed

================================================================================
TROUBLESHOOTING
================================================================================

If Render deployment fails:
1. Check builds logs in Render dashboard
2. Verify all environment variables are set
3. Ensure MONGO_URI and JWT_SECRET are correct
4. Try manual redeploy

If Vercel deployment fails:
1. Check deployment logs in Vercel dashboard
2. Verify VITE_API_URL is correct Render backend URL
3. Ensure root directory is set to "frontend"
4. Try redeploying

If API calls fail:
1. Check browser console (F12)
2. Verify VITE_API_URL matches actual backend URL
3. Check network tab for CORS errors
4. Verify backend is running on Render
